| 관련 스킬 | `mobile-long-press-selection`, `setup-wizard` |

## 목표
Android 뒤로 가기 키를 누르면 앱이 바로 닫히지 않고, 방금 한 일을 하나씩 되돌린다.

## 착수 전 확정
- 2026-11-06 사용자 요청: "각 기능중에 이전상태로 돌아가기가 너무 어렵다. back키를 눌렀을때 바로 이전상태로 돌아가게 해줘"
- 원인: Capacitor 코어는 뒤로 가기 키를 다루지 않아 시스템 기본 동작(앱 나가기)이 적용됐다. 화면 안 상태는 기록에 없었다.

## 범위
- **In**:
  - 네이티브: `Shell` 플러그인(`ready`, `exit`, `back` 이벤트), `MainActivity`의 `OnBackPressedCallback`(웹이 듣기 전에는 시스템 기본)
  - 웹: `app:back` 이벤트 처리 순서(화면 안 상태 → 이전 화면 → 홈 → 나가기), 기록 깊이(`history.state.depth`), `useBackHandler`
  - 화면별 등록: 메뉴, 읽기(패널, 장 고르기, 검색 탭, 구절 선택), 마법사 이전 단계, 원고 추가·미리보기·삭제 확인, 스타일 프로필 확인, 말씀 구성표 삭제 확인, 라이브러리·페르소나 양식과 삭제 확인, 생성 요청 취소, txt 역본 가져오기 단계와 삭제 확인, 연결 삭제 확인, 백업 포함 확인, 만든이 펼친 라이선스
- **Out**: 읽던 장 이동 기록(장을 바꿔도 기록이 쌓이지 않음), 입력 중 내용 버림 확인, iOS(뒤로 가기 키 없음).

## 테스트 요구사항
- 단위(`tests/unit/app/back.test.ts`): 깊이 증가·유지, 링크로 만든 항목 깊이, 최신 처리기 먼저 하나씩, 이전 화면, 직접 연 화면은 홈, 홈과 첫 실행 마법사는 나가기, 이벤트는 남은 것이 없을 때만 나가기.
- E2E(`tests/e2e/back.spec.ts`, `app:back` 보내기): 마법사 이전 단계와 첫 단계, 메뉴 닫기 후 이전 화면, 읽기 패널 → 선택 해제 → 이전 화면, 라이브러리·원고 양식, 만든이 라이선스.
