## 설계 상세
- 본문 원문은 번들 DB(또는 사용자가 선택한 역본)에서 가져와 프롬프트에 넣는다. LLM이 쓴 구절 텍스트는 표시하지 않고, 인용은 DB 원문으로 다시 채운다(규칙 15).
- 프롬프트 금지 사항: 실존 목회자 이름, 교리 단정, 본문 밖 인용. NIV 등 `excluded_bibles`와 권리 있는 역본 본문은 넣지 않는다. 프롬프트 버전은 `gen_cache`·결과 메타에 기록.
- 출력 언어는 UI 언어. ko 길이 800~1200자(공백 포함 그래핌, 초안 본문만 — 덧붙이는 예시·한마디 제외, DESIGN 3.8·7.1), en 550~750단어(`i18n.english_length_words`).
- 검증 순서: JSON 파싱 → 구조(`examples` 2, `humor` 2) → `verse_refs`가 입력 범위 안 → 길이 → 금지 표현·실존 목회자 패턴("○○ 목사처럼" 등) → 복제 검사 → 유머(7.2).
- 재시도: 사유를 합쳐 최대 1회(`max_retries_validation`). 복제 감지 시 일치한 발췌를 빼고 재시도. 재시도도 일일 한도에 포함.
- 유머만 실패하면 가벼운 한마디를 빼고 나머지를 보여준다(7.2). 초안·예시가 재시도 후에도 실패하거나 호출 실패(오류·타임아웃·한도)면 실패 결과를 보이지 않고 말씀 구성표 + 라이브러리 검색 결과를 보여준다.
- 복제 검사 원천: 참고 발췌, 가져온 역본 본문(인터페이스). 검사 대상: 결과 텍스트에서 번들 역본 인용 블록 제외.
- 렌더링: React 텍스트 노드만. 결과 상단·하단에 AI 초안 안내(ko/en 고정 문구).
- 전송 안내: 호출 전 "본문, 키워드, 페르소나, (동의한 경우) 발췌·스타일 요약이 [제공자]로 전송됩니다" 1회 확인. 원고 발췌는 `consent_log(external_transfer)`가 있을 때만 포함.
- `gen_cache`: 키 = 해시(프롬프트 버전, 제공자, 모델, 입력), 본문 AES-GCM 암호화.

## 테스트 요구사항
- 단위: `buildPrompt` 섹션 순서, 발췌 최대 3개, 동의 없으면 발췌 미포함, 스타일 프로필 없으면 블록 생략, NIV·제외 역본 텍스트 미포함, ko/en 템플릿 선택과 버전 문자열.
- 단위: 실존 목회자 이름·"○○ 목사처럼" 입력이 페르소나 블록에 들어가지 않음.
- 단위(픽스처): 정상 응답 통과; JSON 아님; `examples` 1개; `verse_refs` 범위 밖; ko 799자·1201자; en 549·751단어; 금지 주제 한마디; 목회자 흉내 표현; 발췌와 20자 일치; 번들 KJV 인용 블록은 20자 넘게 일치해도 통과.
- 단위(모의 fetch 순서): 1차 실패 → 2차 성공 시 결과 표시, fetch 2회; 1차·2차 실패 시 fallback, fetch 정확히 2회(3회째 없음); 복제 감지 재시도 요청에 해당 발췌 없음.
- 단위: 유머만 실패 → 한마디 제외, 예시·초안 표시.
- 단위(실패 주입, 구 10단계): 401, 429, 타임아웃, 네트워크 오류, 일일 한도 초과 각각 → 구성표·라이브러리 결과 반환.
- 단위: 재시도 포함 호출 수가 `local_stats`에 반영.
- 단위: `gen_cache` 덤프에 결과 평문 없음, 캐시 적중 시 fetch 0회.
- E2E(모의 응답): 선택 → 삶에 닿는 예시 → 전송 안내 → 결과 패널에 AI 초안 안내, 근거 절 링크 동작; `<script>`·`<img onerror>`가 든 응답이 문자 그대로 표시되고 실행되지 않음.
- E2E: 키 없음 상태에서 액션 바 "가벼운 한마디" → 라이브러리 화면, 외부 요청 0건.
- E2E: 영어 UI + KJV 본문, 한국어 UI + KJV 본문(설명 한국어, 인용 KJV 원문).
