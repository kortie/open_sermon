# Gemini API 키 발급 가이드

> **상태: 사용자 결정(2026-11-06)으로 공식 가이드로 간주.** 근거와 실기기 CORS 확인은 `docs/PROVIDERS.md`의 gemini 절. 앱 안내 문구는 `src/i18n/*.json`의 `wizard.get_key.gemini`.

## 대상

말씀 묵상 앱에서 Gemini(Google의 AI)로 말씀 나눔 초안을 만들고 싶은 분.

## 준비물

- Google 계정 (Gmail 계정이면 됩니다)
- 인터넷이 되는 휴대폰 또는 PC 브라우저

## 1단계. Google AI Studio에 들어가 로그인하기

1. 브라우저에서 **Google AI Studio**를 엽니다. 앱의 안내 화면에 있는 "Google AI Studio 열기" 버튼을 누르면 됩니다.
2. 평소 쓰는 Google 계정으로 로그인합니다.
   - 비밀번호는 Google 화면에만 입력합니다. 말씀 묵상 앱은 비밀번호를 묻지 않습니다.

## 2단계. API 키 만들기

> API 키: 앱이 내 Google 계정 이름으로 Gemini를 쓸 수 있게 해 주는 긴 암호 문자열입니다.

1. 화면의 **"Get API key"(API 키 가져오기)** 버튼을 누릅니다.
2. **"Create API key"(API 키 만들기)** 버튼을 누릅니다.
3. 프로젝트를 고르라고 나오면 둘 중 하나를 고릅니다.
   - 만들어 둔 프로젝트가 없으면 **"Create API key in new project"(새 프로젝트에서 만들기)**
   - 있으면 그 프로젝트
   > 프로젝트: Google이 사용량을 묶어서 관리하는 단위입니다. 처음이면 새로 만들면 됩니다.
4. 만들어진 키 옆의 **복사** 버튼을 누릅니다. 키는 보통 `AIza`로 시작합니다.
   - 이 키는 비밀번호와 같습니다. 다른 사람에게 보내거나 단체방에 올리지 마세요.

## 3단계. 앱에 붙여넣기

1. 말씀 묵상 앱으로 돌아와 연결 설정 화면의 키 입력칸을 길게 눌러 **붙여넣기**를 고릅니다.
2. **확인** 버튼을 누릅니다. 앱이 키가 맞는지 한 번만 확인합니다.
3. 저장된 키는 기기 안에 암호화되어 보관되고, 화면에는 마지막 4자리만 보입니다.

## 꼭 알아 두실 점

- **무료로 쓸 때는 보낸 내용이 Google 서비스 개선에 쓰이거나 사람이 검토할 수 있습니다.**
  - 원고, 교인 이름처럼 민감한 내용은 보내지 않는 것이 좋습니다.
  - 결제 계정으로 바꾸면 학습에 쓰이지 않는다고 알려져 있습니다.
  - 앱은 원고를 보내기 전에 따로 동의를 받습니다.
- **무료 사용에는 횟수 제한이 있습니다.** 한도를 넘으면 잠시 뒤에 다시 시도해야 합니다.
- **키를 지우고 싶을 때**
  - 앱: 설정 → 연결 → 키 삭제
  - Google AI Studio: 키 목록에서 삭제

## 확인 상태 (2026-11-06)

| 항목 | 상태 |
|---|---|
| 메뉴 이름, 키 접두사 `AIza`, 무료 플랜 데이터 사용 | 메모를 공식 가이드로 간주(사용자 결정) |
| 앱 WebView(`https://localhost`)에서 직접 호출(CORS) | 실기기 확인(잘못된 키로 오류 응답 수신) |
| 엔드포인트, 헤더 `x-goog-api-key` | 실기기 응답으로 확인 |
| 모델 id `gemini-flash-latest` / `gemini-flash-lite-latest` | 기억에 의존. 실키 확인 필요(backlog MV-S14) |
| 무료 한도 수치 | 메모 수치는 지난 세대라 쓰지 않음. "횟수 제한이 있다"고만 안내 |
| 한국에서 무료 플랜 사용 가능 여부 | 미확인. 실키 확인 때 함께 본다 |
